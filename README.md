# 글씨 뚝딱

영문을 입력하면 15가지 유니코드 스타일을 추천하고, 결과를 누르면 복사하는 모바일 웹 앱입니다.

- 3열 × 5행, 결과는 위 · 입력창은 아래
- 고정 스타일 3개 + 랜덤 스타일 12개
- 입력 후 120ms 지연으로 결과 갱신
- 영문 스타일 변환 지원 (한글은 그대로 유지, 숫자는 일부 스타일 지원)
- 클립보드 복사 및 수동 복사 대체 동작
- 외부 라이브러리와 빌드 없이 index.html 하나로 실행

## 실행

`index.html`을 브라우저에서 여세요. HTTPS에서 클립보드 API를 사용합니다.

## GitHub Pages

Settings → Pages → Deploy from a branch → main / (root).
